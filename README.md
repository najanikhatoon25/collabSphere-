# CollabSphere 🚀

**An AI-Powered Developer Collaboration Platform**

CollabSphere is a full-stack web application designed to help developers collaborate, manage projects, write notes, and use AI-powered tools in one workspace.

## 🎯 Project Overview

CollabSphere combines project management, collaborative documentation, and Generative AI to make developers' workflows easier.

## ✨ Planned Features

- User Registration and Login
- JWT Authentication with HTTP-only Cookies
- Project Creation and Management
- Add Members to Projects
- Markdown Notes Editor with Live Preview
- AI-Powered Code Explanation
- AI-Based README Generation
- File Upload and Preview
- Basic Contribution Analytics
- Public Project Sharing

## 🛠️ Tech Stack

**Frontend**
